# Расписание занятий Planovo (Planovo Schedule)

Специализированное Android-приложение для студентов и преподавателей, ориентированное на оперативный мониторинг времени занятий, их динамических статусов (идёт сейчас, скоро, завершено, отменено), отслеживание изменений в расписании и своевременные системные уведомления.

## User Review & Critical Decisions

> [!IMPORTANT]
> **Уточненные требования пользователя**:
> - **Формат отображения**: Вместо классической сетки-календаря фокус сделан на информативном дашборде расписания занятий: точное время, текущий статус (в реальном времени), обратный отсчет до начала/конца, преподаватель, аудитория и индикация изменений.
> - **Источник данных**: URL группы 41 (`https://planovo.pro/api/v1/public/groups/41/calendar.ics`) предзагружен по умолчанию с возможностью быстрого переключения ID группы или ввода своего URL в настройках.
> - **Уведомления**: Системные пуш-напоминания за 15 минут до начала занятия (с возможностью гибкой настройки времени в параметрах).
> - **Среда выполнения**: Нативное Android-приложение на Kotlin + Jetpack Compose в строгом соответствии с Material Design 3 и премиальной тёмной темой (вместо Flutter, согласно возможностям сборочной среды Android).

## 1. Overview & Core Concept

- **Назначение**: Предоставить мгновенный и надежный доступ к расписанию занятий группы, избавляя от необходимости вручную открывать ссылки и проверять отмены.
- **Целевая аудитория**: Студенты, ученики и преподаватели секций и студий, использующих CRM Planovo (`planovo.pro`).
- **Ключевая ценность**:
  - Быстрый просмотр: что идёт сейчас, какое следующее занятие и сколько минут осталось.
  - Детектор изменений: автоматическое сравнение синхронизированных версий расписания с выделением перенесённых, отменённых или изменённых пар/уроков.
  - Автономность (Offline First): кэширование в локальную базу данных Room — расписание доступно даже без интернета.
  - Точные уведомления без пропусков через Android `AlarmManager`.

## 2. User Experience & Visual Design

### Ключевые экраны и сценарии

1. **Главный экран (Schedule Dashboard)**:
   - **Hero Card текущего/следующего занятия**: Крупная динамическая карточка с пульсирующим бейджем статуса ("Идёт прямо сейчас" с прогресс-баром времени урока или "Следующее занятие через 25 минут").
   - **Интерактивная лента дней (Day Selector Strip)**: Горизонтальный селектор дней недели (Вчера, Сегодня, Завтра и т.д.) с индикацией количества занятий и точками изменений.
   - **Хронологический список занятий дня**:
     - Временной интервал (например, `14:00 — 15:30`) и длительность.
     - Название предмета/направления.
     - Преподаватель и аудитория/зал.
     - Цветовые чипы статусов:
       - 🟢 **Идёт сейчас** (Emerald pulse)
       - ⏳ **Скоро** (Amber accent)
       - ⚪ **Предстоит** (Neutral M3 surface)
       - 🔴 **Отменено** (Terracotta error container с перечеркнутым временем)
       - 🟡 **Изменено** (Warning container с бейджем "Время изменено")
       - ✔️ **Завершено** (Dimmed subtle outline)
   - **Пулл-ту-рефреш (Pull to Refresh)** и плавающая кнопка быстрого обновления.

2. **Экран журнала изменений (Changes Log)**:
   - Список недавних изменений, обнаруженных при последней синхронизации (новые занятия, перенос времени, отмена занятия, смена преподавателя или аудитории).

3. **Экран настроек (Settings & Sources)**:
   - Ввод и проверка URL или ID группы Planovo (по умолчанию группа 41).
   - Настройка времени уведомления: за 5, 10, 15 (по умолчанию), 30 или 60 минут.
   - Переключатель вибрации и звука для напоминаний.
   - Тестирование уведомлений прямо из настроек.

### Визуальный стиль и Material 3 Dark Theme

- **Цветовая палитра**:
  - Глубокий темный фон: `Color(0xFF0F141C)` и `Color(0xFF161D26)`.
  - Акцентный основной цвет: Энергичный циан/бирюза `Color(0xFF4DD0E1)` и электрик `Color(0xFF80D8FF)`.
  - Вторичные акценты: Мягкий фиолетовый `Color(0xFFB388FF)` для аудиторий и преподавателей.
  - Семантические цвета: Изумрудный (`0xFF00E676`) для активных занятий, коралловый (`0xFFFF5252`) для отмен.
- **Типографика**: Четкая иерархия Material 3 (моноширинный акцент для точного времени `JetBrains/Roboto Mono style`, крупный `TitleMedium` для названий предметов).
- **Микро-взаимодействия**: Плавные анимации раскрытия деталей занятия, индикатор текущего прогресса занятия.

## 3. Key Product Decisions & Trade-Offs

- **Парсинг iCalendar (RFC 5545)**:
  - *Решение*: Легковесный, надежный и высокопроизводительный нативный Kotlin-парсер формата `.ics` без громоздких внешних устаревших Java-библиотек. Поддержка `DTSTART`, `DTEND`, `SUMMARY`, `DESCRIPTION`, `LOCATION`, `STATUS`, `UID`, `SEQUENCE`, `LAST-MODIFIED`.
  - *Преимущество*: Мгновенный парсинг даже сотен событий, отсутствие конфликтов версий библиотек, полная поддержка Android API 24+.
- **Хранение данных и обнаружение изменений (Room Database)**:
  - *Решение*: Локальная база данных Room с таблицей событий `schedule_events` и таблицей журнала изменений `schedule_changes`.
  - *Логика детекции*: При загрузке свежего `.ics` происходит сверка по `UID` и хэшу параметров. Если время или статус изменились, событие помечается флагом `hasChanges = true`, а в журнал записывается запись о характере изменения.
- **Системные уведомления**:
  - *Решение*: Android `AlarmManager` с вызовом `NotificationManager` через `BroadcastReceiver`.
  - *Преимущество*: Точное срабатывание в заданное время даже в фоновом режиме устройства.

### Модели данных

1. `ClassEvent`:
   - `id`: String (UID события)
   - `title`: String (Название дисциплины/занятия)
   - `description`: String (Заметки, группа, темы)
   - `teacher`: String (Выделенный преподаватель)
   - `location`: String (Аудитория, зал, ссылка)
   - `startTimeMillis`: Long
   - `endTimeMillis`: Long
   - `status`: EventStatus (`CONFIRMED`, `CANCELLED`, `TENTATIVE`)
   - `isChanged`: Boolean
   - `changeDescription`: String?

2. `ClassStatus`:
   - `ONGOING` (идёт сейчас, с процентом прогресса)
   - `UPCOMING_SOON` (начнется менее чем через 60 минут)
   - `SCHEDULED` (запланировано на будущее)
   - `COMPLETED` (уже завершено)
   - `CANCELLED` (отменено)

## 5. Implementation Roadmap

1. **Базовая конфигурация и зависимости**:
   - Обновить `metadata.json` и строковые ресурсы (`app_name = "Planovo Расписание"`).
   - Настроить разрешения в `AndroidManifest.xml` (`INTERNET`, `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED`, `VIBRATE`).
2. **Сетевой слой и ICS парсер**:
   - Реализовать `IcsParser` для разбора стандартных полей iCalendar с корректной обработкой часовых поясов и форматов дат.
   - Реализовать `PlanovoApiService` через OkHttp для загрузки `.ics` файла.
3. **Хранилище данных (Room)**:
   - Создать `AppDatabase`, `ScheduleDao`, сущности `ScheduleEntity` и `ChangeEntity`.
   - Реализовать алгоритм сравнения версий (Diff Engine).
4. **Менеджер системных уведомлений**:
   - Создать `AlarmReceiver` и `NotificationHelper` с каналом уведомлений "Напоминания о занятиях".
   - Реализовать планирование уведомлений за 15 минут до каждого предстоящего занятия.
5. **UI & Material 3 Dark Theme**:
   - `Theme.kt`: Глубокая темная тема с акцентными токенами M3.
   - `HeroCurrentClassCard`: Карточка активного занятия с таймером и прогрессом.
   - `DaySelectorStrip`: Горизонтальный календарный скроллер дней с подсчетом пар.
   - `ClassCard`: Информативная карточка с бейджами статусов и акцентом на времени.
   - `ChangesScreen` & `SettingsDialog`: Управление группой и журналом изменений.
6. **Верификация**:
   - Проверка компиляции `compile_applet`.
